# 模式 5：场景化素人仿写

话题词按 [SKILL.md 的原文话题词保留规则](../SKILL.md)执行；每版正文末尾完整附上来源原话题，不参与改写。

## 目标

把用户提供的原文改写成适合小红书店铺发布的素人种草笔记。保留产品事实和有效种草逻辑，重做措辞、句式、细节与场景，降低商销感。

## 输入

确认以下四项后再写：

- 商家产品或品类；
- 目标人群；
- 产品用途或作用；
- 需要改写的完整原文。

可选补充：真实卖点、材质/成分、必须保留的关键词、禁用表述。不得把用户未提供或无法验证的信息补成事实。

## 写前规划与事实

先读[模式5写作约束](mode-5-contract.json)。`variation`的场景、重点、结构必须使用其中的稳定ID，不能自造同义标签。参考历史正文，先选择不同的内容任务，再写稿：比如把“出门找东西”换为“买之前先盘点是否需要”，而非把“出门时”改成“出门前”。与最近稿件至少改变两个维度，正文必须真正体现差异。

把用户实际提供的每项产品信息记录为`product_facts`，含`kind`（如color/material/purpose/price/size/capacity/touch/experience/effect）、`value`、`source`、`status`。没有依据的项目保持未知。正文只使用已知事实；不能借原文的叙事语气补齐规格或体验。

若没有真实购买/使用素材，全文使用“我会怎样选、准备怎样安排、什么条件下适合我”的选择视角。情境可写成设想，不能写成已经发生的个人经历。只有已有真实经历素材时才使用实际体验视角。不要为写得像真人而补造购买、使用效果、触感、容量或价格。

## 写作规则

- 正文（不含原文话题尾部）控制在约 180 个汉字，通常以 160–210 个汉字为宜；用户另有字数要求时以用户要求为准。
- 正文固定分为三段，末尾话题不计段落数；三段按已选结构推进，不再固定成“困扰→使用见效→推荐购买”。
- 第一人称表达自己的选择或观察，语气自然、口语化、通俗易懂；是否写已购买、已使用，完全取决于真实素材。
- 优先写通勤、上课、工作、逛街、居家、学习等与目标人群真实相关的日常场景，加入动作、困扰、感受或情绪变化，让读者能代入。
- 提供适量情绪价值，但不要堆网络热词、夸张感叹、硬广口号、参数罗列、催单话术或明显商销表达。
- 内容要有因果和推进关系，不写成互不相干的卖点清单。
- 保留必要产品事实，不照搬原文连续表达。改写后与原文的措辞及句式重复率目标不超过 30%；交付前按连续短语、句式和段落顺序做近似自检，发现明显复用就继续重写。不得声称完成了无法精确计算的专业查重。
- 第一人称只作为叙述视角，不伪造具体使用时长、效果、购买次数、朋友反馈或个人经历。缺少真实体验素材时，使用基于已知产品事实的日常选择、观察和适用场景表达。
- 避免绝对化、医疗化及无法证明的功效承诺；产品“作用”只能写到用户提供且可支持的程度。

## 输出

生成后按跨会话流程检查，再由一次独立内容复核读取本篇、最近旧稿与事实表，逐句检查事实，并用新旧正文的具体片段说明至少两个实质差异。该复核由助手内部执行，不要求学员填写检查表。复核发现问题时按既有重写次数和调用授权边界处理；只交付检查及保存成功的正文。

默认输出三段完整正文；原文有话题时，另起一行逐字附上完整话题尾部。不附分析、结构标签、查重承诺或提示词。用户要求标题时，再补充 3–5 个不同切口的标题。
