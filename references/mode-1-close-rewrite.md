# 模式 1：1:1 贴近仿写

## 目标

像同一作者围绕同类主题写出的另一篇笔记：贴近原素材，不发挥、不加戏。仿写只换表达“皮肤”，不换结构、信息块和情绪节奏“骨架”。

## 内部分析（不输出）

识别段落数量及大致字数、信息块顺序与比例、开头钩子、情绪锚点、卖点/观点位置、收尾方式，以及语气、句式、用词、人称。

识别并原样保留：

- 搜索流量词，包括用户指定关键词；
- 情绪表达词，如“班味”“发疯”“松弛感”；
- 行业专有词、品牌名、产品名和垂类术语。

## 重写约束

- 段落数量、信息顺序、篇幅比例、观点与论据数量均与原帖对应。
- 保持原帖情绪基调、人称和语感，只改非关键词部分的用词、句式、语态与信息密度。
- 仅在原帖已有感官描写的位置做同等程度的感官改写。
- 禁止新增比喻、金句、名言、经历、案例、观点延伸或自创风格。
- 忠于已知事实；新产品信息不足时先追问，不可把原产品事实挪给新产品。
- 用户指定的搜索关键词完整保留，自然出现至少 3 次，并分布在标题、开头、中段、结尾中的至少 3 个位置。若用户未指定，不强行凑次数。

## 输出

默认直接输出标题和完整正文，不输出分析或解释。保持原帖数字样式；若用户无要求而需要序号，使用 `1⃣️ 2⃣️ 3⃣️`。
